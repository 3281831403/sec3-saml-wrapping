攻击者把一份合法断言的签名节点挪到另一份伪造断言上，校验器从头到尾验的还是原来那一份：被移动的签名仍然通过，伪造断言因此被当成可信身份。签名必须绑定到唯一的断言节点；引用标识必须唯一并指向实际被签的内容；校验必须针对断言节点本身而不是顶层文档；断言标识只能使用一次；受众必须精确匹配；批量校验中的每份文档必须彼此独立。不变量是：任何被移动或被包裹的签名都必须校验失败，同一断言第二次提交必然失败。
